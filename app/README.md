# app — prototipo (Streamlit)

Demostración en vivo para el jurado: entrada (zona o coordenadas) → respuesta de los modelos.

- Carga: artefactos de `modelos/supervisado/`, `modelos/no_supervisado/` y `modelos/refuerzo/`.
- Ejecutar: `streamlit run app/app.py` (dependencias en `requirements.txt`).
- Pendiente: `app.py`, el mapa interactivo (Folium/Plotly) y la vista de priorización.
